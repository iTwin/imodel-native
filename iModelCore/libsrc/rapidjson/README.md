# Updating RapidJSON

Follow the repository's [third-party library update workflow](../../../.github/skills/update-third-party-lib/SKILL.md) when updating RapidJSON.

Whenever RapidJSON is updated, update [RapidJsonNugetLicense.json](RapidJsonNugetLicense.json) in the same change. Verify the upstream version, SPDX license identifier, and version-pinned license URL.

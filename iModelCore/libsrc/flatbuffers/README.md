# Updating FlatBuffers

Follow the repository's [third-party library update workflow](../../../.github/skills/update-third-party-lib/SKILL.md) when updating FlatBuffers.

Whenever FlatBuffers is updated, update [FlatBuffersNugetLicense.json](FlatBuffersNugetLicense.json) in the same change. Verify the upstream version, SPDX license identifier, and version-pinned license URL.

# Updating FreeType

Follow the repository's [third-party library update workflow](../../../.github/skills/update-third-party-lib/SKILL.md) when updating FreeType.

Whenever FreeType is updated, update [Freetype2NugetLicense.json](Freetype2NugetLicense.json) in the same change. Verify the upstream version, SPDX license identifier, and version-pinned license URL.
